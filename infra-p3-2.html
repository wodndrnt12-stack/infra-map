PHASE 3 · 3.2

📥 입력·시작 훅  2개

내가 말을 걸거나 세션이 시작될 때 도는 훅 — 규칙을 상기시키고, 직전 대화를 기억한 채 시작하게 합니다.

매번 백지에서 시작하지 않으려면 두 가지가 필요합니다. "규칙을 다시 일러주기"와 "어제 무슨 얘기 했는지 떠올리기".

💡
rule-reminder
매 입력 시
언제내가 메시지를 보낼 때마다(UserPromptSubmit).
하는 일"승인 전 실행 금지 / 완료 시 검증 / 애매하면 질문" 핵심 규칙을 답변 앞에 자동으로 끼워 넣습니다(additionalContext).
판정입력을 소문자로 훑어 키워드 12종(hook·설정·훅·guard·cron·.json·.js·규칙·config 등)이 보이면 "VE 프로세스 적용 대상" 한 줄을 더 붙입니다.
제약절대 exit 2 금지 — 입력 단계 훅이라 차단하면 내 프롬프트 자체가 막힙니다. 주입 글귀도 30토큰 이하로 유지. 파일엔 안 씀.
연결규칙 체계(P2)를 매 턴 상기시키는 역할.
🌅
restore-context
세션 시작 시
언제세션이 새로 시작될 때(SessionStart: 시작·초기화·압축).
하는 일직전 세션 + 현재 세션에서 각각 최근 5개 메시지를 불러와 "어제 무슨 얘기 했는지" 기억한 채로 시작하게 합니다.
판정config.toml의 봇 이름으로 세션 파일을 고르고(없으면 최신 수정본), s1·s2… 키를 번호순 정렬해 끝 5개만. 한 줄이 200자 넘으면 잘라냄(…).
읽고/쓰고~/.cc-connect/sessions/*.json·config.toml을 읽고, 디버그 사본을 hooks-debug/에 남김.
연결cc-connect 대화 기록에 직접 연결. (압축 시 복원은 restore-session이 따로 담당 — 15개·3단 폴백으로 더 깊게, P3.4)
