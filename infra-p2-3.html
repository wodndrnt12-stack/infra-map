기억 안전 — 메모리 중독 방어
오래된 메모리나 외부 데이터가 현재 시스템 상태를 덮어쓰는 공격(OWASP ASI06)을 막는 4중 방어.
1현재 파일 우선충돌 시 파일시스템 신뢰
2메모리 실행 금지참고용, 코드로 실행 안 함
3모순 검사기존과 충돌 시 사용자 확인
4출처 명시외부 데이터는 source 표기
위반 감지 시 → 작업 중단 후 보고, 사용자 지시 대기.
