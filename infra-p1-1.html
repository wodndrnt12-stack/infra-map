🗺️ 인프라란 무엇인가

우리 봇을 떠받치는 5가지 장치와, 그것들이 디스크 어디에 사는지.

우리 봇(Woong1993bot)은 그냥 Claude 하나가 아니라, 옆에 5가지 보조장치를 달고 일합니다. 이 장치들이 봇을 "매번 백지에서 시작하는 AI"가 아니라 "어제 일을 기억하고, 규칙을 지키고, 실수를 막는 일꾼"으로 만들어 줍니다.

5가지 보조장치
📐
규칙14
항상 지켜야 할 일하는 방식
~/.claude/CLAUDE.md~/.claude/rules/*.md
🪝
훅18+2
정해진 순간 자동 실행되는 동작
~/.claude/settings.json~/.claude/hooks/*.js
🧠
메모리32
까먹지 않으려 저장한 정보
~/.claude/projects/<…>/memory/
📓
세션로그30
날짜별 업무일지
Wiki/02-ai-tools/project-log/
🔌
MCP6
외부 서비스 연결 통로
커넥터 / cmd /c <바이너리>
"한눈에 안 들어왔던" 진짜 이유

이 5가지가 서로 다른 폴더 6곳에 흩어져 있고, 핵심 연결(훅↔로그↔규칙)이 파일 안에 숨어 있어서입니다. 이 지도가 그 흩어진 것들을 한 자리에 모으고, 숨은 연결을 드러내는 게 목적입니다.

디렉토리 구조
# 규칙·훅·메모리·로그가 사는 곳
~/.claude/
├─ CLAUDE.md            # 전역 규칙 (50줄 요약본)
├─ rules/*.md           # 상세 규칙 14개
├─ settings.json        # 훅 등록표 (이벤트→훅)
├─ hooks/*.js           # 훅 스크립트 20개 (등록 18 + 수동 2)
├─ logs/                # 훅이 남기는 기록 (metrics·agents·summaries)
├─ checkpoints/         # 파일 수정 전 백업
└─ projects/<slug>/memory/  # 메모리 32개 + MEMORY.md 목차

~/Desktop/Bot_setting/
├─ CLAUDE.md            # 이 프로젝트 전용 규칙
└─ Wiki/02-ai-tools/project-log/
   ├─ hot.md            # 최신 상태 요약 (세션 시작 시 1번째로 읽음)
   ├─ sessions/*.md     # 날짜별 일지 30개
   └─ MOC.md            # 주제별 색인
