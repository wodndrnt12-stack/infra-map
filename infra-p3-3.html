guard
Bash·PS 실행 직전
하는 일위험한 명령 8종(전체 삭제 rm -rf /, main 강제 푸시, DROP DATABASE, 드라이브 포맷 등)을 정규식으로 검사해, 걸리면 즉시 차단(exit 2).
읽고/쓰고명령어를 읽고, 차단 기록을 guard.log에 남김.
예외시스템 종료·재시작 차단(shutdown·Restart-Computer)은 현재 임시 비활성(코드 주석) 상태 — 봇 운영 편의를 위한 의도적 BYPASS입니다.
💾
checkpoint-pre
Write·Edit 직전
하는 일수정 대상 파일(10MB 이하)의 원본을 백업해 둡니다(되돌리기용, 파일당 최대 5개).
읽고/쓰고대상 파일을 읽어 ~/.claude/checkpoints/에 타임스탬프 이름으로 복사.
연결git을 안 쓰는 작업에서도 "실행 전 되돌릴 수단"을 보장(VE 규칙의 ③번 안전망).
🔑
credential-guard
Write·Edit 직전
하는 일쓰려는 내용에 자격증명 15종(AWS키, GitHub 토큰, 텔레그램 토큰 등)이 섞여 있으면 차단(exit 2). 단, 훅 폴더·예시·플레이스홀더는 허용.
읽고/쓰고쓸 내용을 검사하고, 차단 기록을 credential-guard.log에.
🤖
agent-tracker-pre
Agent·Task 호출 직전
하는 일누구에게·무슨 모델로·무슨 프롬프트로 시켰는지 "시작" 기록을 남깁니다.
읽고/쓰고호출 정보를 읽어 ~/.claude/logs/agents/에 start 이벤트로 기록.
연결끝나면 dispatcher가 같은 파일에 "완료"를 적습니다 → 에이전트 수명 추적 물길(P3.6).
