🕸️ 훅 연결 관계도

훅들은 따로 노는 게 아니라, 공유 폴더를 통해 4개의 물길로 이어집니다 — 한쪽은 쓰고 한쪽은 읽으며 간접 연결됩니다.

"어떤 훅이 어떤 훅과 연결되나"의 핵심 — 훅들은 같은 로그 폴더를 통로 삼아 이어집니다. 아래가 그 지도입니다.

✅ 물길 1 — 성공 기록
도구 사용 → dispatcher로그 3종 기록 → 작업일지·통계·에이전트 → daily-summary 리포트session-log-guard 감시
❌ 물길 2 — 실패 기록
도구 실패 → dispatcher-failure → errors.jsonl + 통계(실패) → analyze-errors 묶기log-rotate 청소
🤖 물길 3 — 에이전트 수명 추적
agent-tracker-pre"시작" 기록 → 같은 agents 파일dispatcher가 "완료" 추가 → daily-summary시작·완료 짝 집계
🔄 물길 4 — 컨텍스트 복원
세션 시작 / 압축 → restore-contextrestore-session → cc-connect 대화 기록 읽기 → 직전 맥락 복원실패 시 hot.md 폴백
📁 공유 폴더 = 훅끼리 이어지는 통로
